BOSS 直聘连接管理

在 Chrome 官方页面登录求职者账号，再通过本地扩展连接。只打开网页不会显示为已连接。

  1. 下载求职端 Chrome 扩展并解压，或使用项目内的 extension 文件夹。
  2. Chrome 打开 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”。
  3. 创建下方配对凭证，粘贴到扩展侧栏。诊断当前岗位或会话，核对后导入或绑定。
